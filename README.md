# SafeWing Technologies - Guardian Bee Portfolio

Welcome to the **Guardian Bee Portfolio** repository for SafeWing Technologies. This project serves as a comprehensive landing page and portfolio, outlining the problem, features, market impact, and future vision of the Guardian Bee initiative.

## 🌟 Overview

The Guardian Bee Portfolio is a modern, responsive web application built with React and Vite. It features a clean, intuitive design with a dynamic dark/light mode toggle. The application guides visitors through various sections to fully understand the value proposition of SafeWing Technologies.

### Key Sections:
- **Hero:** Introduction to Guardian Bee and SafeWing Technologies.
- **About Us:** The mission and team behind the project.
- **Problem:** The specific challenges Guardian Bee addresses.
- **Features:** Core functionalities and benefits.
- **Market:** Target audience and market analysis.
- **Why Now:** Timing and relevance of the solution.
- **Future Vision:** Roadmap and upcoming milestones.
- **Contact:** Ways to get in touch with the team.

## 🛠️ Technology Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** CSS Modules / Vanilla CSS (with dynamic theme support)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Scroll Detection:** React Intersection Observer

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18 or higher) and npm (or yarn/pnpm) installed.

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd SafeWingTechnologies
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:5173` (or the port provided by Vite in your terminal).

## 📄 Scripts

- `npm run dev`: Starts the Vite development server with Hot Module Replacement (HMR).
- `npm run build`: Bundles the application for production.
- `npm run lint`: Runs ESLint to check for code quality and style issues.
- `npm run preview`: Bootstraps a local web server to preview your production build.
